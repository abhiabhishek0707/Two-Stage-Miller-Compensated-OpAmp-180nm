# Two-stage-Op-Amp
Design of a high-performance two-stage Miller-compensated Operational Amplifier (OPAMP) using 180nm semiconductor technology  and simulated in Cadence Virtuoso, including transistor sizing, biasing and frequency compensation, achieving 60 dB gain, 60° phase margin, 30 MHz GBW, 0.8–1.6 V ICMR, and 300 µW power dissipation.
